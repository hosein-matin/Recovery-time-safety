# Reporting issues and proposing changes

For a reproducibility issue, please include the release/version, operating
system, Python and dependency versions, exact root command, and the relevant
error output. Run `python3 reproduce.py --verify` first to check the downloaded
snapshot. Please avoid including credentials or unrelated personal data.

For a mathematical issue, identify the document, theorem or equation, and the
precise assumption or proof step concerned. A counterexample or minimal
calculation is particularly helpful.

Please discuss substantial implementation or theoretical changes in a GitHub
issue before preparing a pull request. Keep benchmark data, numerical timing,
and rigorous certificates distinguishable, and identify any changed protocol.
